블로그 소유자 세션을 등록하고, 삭제 전 점검과 스팸 규칙을 관리합니다.

{# ------------------------------------------------------------ 세션 쿠키 #}

세션 쿠키

댓글 삭제에는 블로그 소유자의 로그인 세션이 필요합니다. 조회는 쿠키 없이도 동작합니다.

진단 필요

세션 상태를 불러오는 중입니다.

등록된 쿠키 없음

보안을 위해 쿠키 이름만 표시합니다. 쿠키 값은 암호화해 저장하며 화면과 로그에 절대 출력하지 않습니다.

붙여넣은 내용은 서버로 한 번 전송된 뒤 암호화되어 저장되며, 이 입력창은 등록 후 비워집니다.
쿠키를 얻는 방법

로그인한 상태에서 자기 블로그를 연 뒤 아래 순서를 따르세요. 브라우저마다 메뉴 이름만 조금 다릅니다.

Chrome, Edge

  1. 블로그에 로그인한 상태에서 F12 키를 눌러 개발자도구를 엽니다.
  2. Network 탭을 선택하고, 페이지를 새로 고칩니다.
  3. 목록에서 아무 요청이나 하나를 고릅니다. 블로그 주소로 시작하는 요청이면 됩니다.
  4. 그 요청을 마우스 오른쪽 버튼으로 누르고 Copy, Copy as cURL 을 차례로 선택합니다.
  5. 복사한 내용을 위 입력창에 그대로 붙여넣고 등록을 누릅니다.

Firefox

  1. F12 키를 눌러 개발자도구를 열고 네트워크 탭을 선택합니다.
  2. 페이지를 새로 고쳐 요청 목록을 채웁니다.
  3. 요청 하나를 오른쪽 버튼으로 누르고 값 복사, cURL로 복사를 선택합니다.
  4. 복사한 내용을 위 입력창에 붙여넣고 등록을 누릅니다.

브라우저에서 자동 가져오기 버튼을 쓰면 이 과정을 건너뛸 수 있습니다. 다만 브라우저가 쿠키 파일을 잠가 두면 실패할 수 있으므로, 실패하면 위 방법을 사용하세요.

{# --------------------------------------------------------- 1건 시험 삭제 #}

1건 시험 삭제

대량 삭제 전 반드시 1건으로 확인하세요. 삭제 응답의 형태를 검증해 실제 실행에서의 실패를 막습니다.

이 기능은 드라이런이 아닙니다. 입력한 댓글 1건이 블로그에서 실제로 삭제되며 되돌릴 수 없습니다.

댓글 관리 화면의 목록에서 대상 댓글 번호를 확인할 수 있습니다.
